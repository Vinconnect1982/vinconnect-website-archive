# Agents working on VINCONNECT

Read this before you edit the site.

The shared log is [docs/SITE-CHANGELOG.md](docs/SITE-CHANGELOG.md).

Before you change a page, read that file from the top and check the latest entry. If another person or agent has already shipped or agreed the change, do not overwrite it.

After you change a page, add an entry at the top of docs/SITE-CHANGELOG.md in the same commit. Say shipped or agreed, the date, the path, and what the next agent must not undo.

A site change with no log entry is not finished.
